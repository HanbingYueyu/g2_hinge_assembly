# VLM 三项判别迁移与运行说明

> 当前工程运行时已切换到局域网 OpenAI-compatible 服务：`http://192.168.30.12:8000/v1`。客户端使用 `VLM_LAN_API_KEY`，本文件中关于北京 DashScope 或本地 vLLM 的内容仅保留作历史迁移记录，不是当前默认部署方式。

整理日期：2026-09-16。本目录可以整体复制到另一台 Linux 电脑，不依赖原电脑的 `/tmp` 文件。

## 1. 包含的三个任务

1. `pin`：判断铰链尖端带线缆穿过中心的凸轴 B 是否完全插入。
2. `c-hole`：只判断是否有明显冰箱小孔 C 漏在铰链板外，不判断 D 孔内部的轻微偏心。
3. `gripper`：判断夹爪是否夹住铰链、尚未夹住，或者抓住后掉落。

三项都是视觉语义审查，不得直接控制机械臂。深度图、SAM、ArUco 和 STL 都不是这三个便携命令的必需输入。

## 2. 当前远程 API 配置

| 项目 | 值 |
|---|---|
| 服务商 | 阿里云百炼 DashScope |
| 地域/Key | 北京站 Key |
| 协议 | OpenAI-compatible Chat Completions |
| URL | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` |
| 模型 | `qwen3.8-flash` |
| temperature | `0` |
| seed | `42` |
| enable_thinking | `false` |
| 图片格式 | Base64 Data URL，JPEG/PNG |

新加坡地域接口通常是 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1/chat/completions`，但本包的真实 Key 和默认 URL 都是北京站，不能混用地域。

真实密钥已按要求放入 `config/vlm.env`，权限为 `600`。该文件和压缩包都属于敏感文件，不要上传 Git、网盘公开链接或聊天。迁移完成后，推荐到百炼控制台轮换 Key。

## 3. 在新电脑安装

需要 Python 3.8 或更高版本：

```bash
cd "VLM三项判别迁移包_20260916"
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
chmod 700 run.sh
chmod 600 config/vlm.env
```

安全确认 Key 已存在但不打印明文：

```bash
grep -q '^DASHSCOPE_API_KEY=.' config/vlm.env && echo "Key present"
```

## 4. 运行方式

每个 `--image` 后面给一张图；重复参数表示多视角或连续帧。输出为严格 JSON。

### 4.1 凸轴 B 是否插入

建议输入最终时刻的右、左、头部相机 RGB 图；右侧能看清 B 轴接触关系的视角最重要。

```bash
./run.sh pin \
  --image /path/to/right_final.jpg \
  --image /path/to/left_final.jpg \
  --image /path/to/head_final.jpg
```

输出示例：

```json
{"pin_inserted":true,"state":"inserted","confidence":0.96,"best_view":"右侧视角","reason":"B轴已落入安装孔且贴合"}
```

### 4.2 明显 C 孔是否漏在板外

优先输入能看见铰链板外缘和黑色冰箱表面的左侧近景。该任务有意忽略 D 孔内部轻微不同心。

```bash
./run.sh c-hole \
  --image /path/to/left_final.jpg \
  --image /path/to/right_final.jpg
```

输出示例：

```json
{"obvious_c_leak":true,"c_count":3,"c_locations":["板左上外侧"],"confidence":0.95,"best_view":"左侧视角","reason":"板外清楚可见三个冰箱小孔"}
```

### 4.3 夹爪是否掉落

图片固定按以下顺序输入：当前全图、当前夹爪近景、可选的抓取成功参考近景。

```bash
./run.sh gripper \
  --image /path/to/current_full.jpg \
  --image /path/to/current_gripper_crop.jpg \
  --image /path/to/post_grasp_reference.jpg
```

原流程采用的夹爪默认裁剪框为 `(80,120,560,480)`，来源是左腕 D405。完整 ROS 实现保存在 `original_gripper_ros/vlm_grasp_monitor.py`，原详细说明在同目录。

## 5. 请求实际是怎样构造的

`src/vlm_three_checks.py` 的执行顺序：

1. 从 `config/vlm.env` 加载 Key；
2. 读取对应 `prompts/*.txt`；
3. 对 `pin` 和 `c-hole`，先上传包内参考图，再上传待测图；
4. 图片编码为 `data:image/jpeg;base64,...`；
5. HTTP POST 到北京 OpenAI 兼容 URL；
6. 解析 `choices[0].message.content` 中的 JSON；
7. 标准输出只打印判别 JSON，错误打印到标准错误。

核心请求结构：

```json
{
  "model": "qwen3.8-flash",
  "messages": [{"role":"user","content":[
    {"type":"text","text":"任务提示词"},
    {"type":"image_url","image_url":{"url":"data:image/jpeg;base64,..."}}
  ]}],
  "temperature": 0,
  "seed": 42,
  "enable_thinking": false,
  "max_tokens": 256
}
```

也可手动覆盖配置：

```bash
VLM_MODEL=qwen3.8-flash ./run.sh pin --image /path/to/image.jpg
./run.sh pin --api-url https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions --image /path/to/image.jpg
```

## 6. 提示词与参考图

- `prompts/pin_inserted.txt`：目标明确限定为凸轴 B，并强调不能因铰链大致放平就判断插入。
- `references/pin/pin_target_B.jpg`：包含目标 B 的现场核对图。
- `references/pin/pin_state_examples.jpg`：8 段现场状态总览，用于给模型建立正负状态概念。
- `prompts/obvious_c_leak.txt`：只查板外明确 C 孔，明确禁止把 D 孔内反光/月牙当作外漏。
- `references/c_hole/hole_groups_C_D.jpg`：现场 C/D 与候选位置核对图。
- `references/c_hole/hole_state_examples.jpg`：现场多状态总览。
- `prompts/gripper_drop.txt`：夹爪抓住/未抓/掉落/未知四态提示词。

`references/review_all/` 保存了全部 8 段人工核对卡，便于换电脑后回看任务定义。

## 7. 已验证结果和边界

- 凸轴插入：使用 `qwen3.8-flash`、固定随机种子和参考图，在现有 8 段上为 8/8。
- 明显 C 外漏：`102252、102318、102341、102419` 检出；`100130、101601、102606` 正确判无明显外漏。
- `101514`：用户确认 D 孔内部错位，但没有明确板外 C；因此不计入粗粒度 C 外漏任务准确率。
- D 孔内部精细偏心没有作为生产输出：Flash 和 Max 都会把正常孔壁、反光和透视月牙误报为偏心。
- 夹爪方案是低频旁路语义监视器；原 ROS 版使用当前全图、夹爪近景、抓取后参考近景，并做稳定投票。
- 远程 API 可能有排队和长尾延迟，不能作为硬实时安全控制器。

完整现场标签见 `docs/verified_results.json`。

## 8. 离线验证与故障排查

不消耗 API 额度的测试：

```bash
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest -q tests/test_package.py
```

若没有 pytest：

```bash
python -m pip install pytest
```

常见错误：

- `DASHSCOPE_API_KEY is missing`：检查 `config/vlm.env`。
- HTTP 401：Key 无效或地域不匹配。
- HTTP 429：额度、并发或限流问题。
- 请求超时：增大 `--timeout 120`，并减少不必要图片数量。
- JSON 解析失败：保留原始错误，检查模型是否被替换为不支持视觉或不遵循 JSON 的模型。
