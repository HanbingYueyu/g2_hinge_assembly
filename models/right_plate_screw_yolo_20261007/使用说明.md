## 裁剪和计数方式

程序接收第二张参考图对应的右手相机完整 **1280×1056** 原图，然后裁剪为第一张图对应的板件局部视野。裁剪坐标以原图左上角为原点：

| 参数 | 像素值 |
| --- | --- |
| 左上角 `(x,y)` | `(525,435)` |
| 右下角（不包含） | `(780,815)` |
| 宽×高 | `255×380` |
| NumPy 切片 | `image[435:815, 525:780]` |

这是按两张参考图的对应关系确定的实用裁剪范围。原图和裁剪示例在 `../../runs/right_plate_screw_yolo/20261007_v1/crop_box_check/roi_on_original.jpg`、`crop_example.jpg`。固定范围适用于目前相机和工位位置。

输入必须是完整 1280×1056 原图，不能先自行裁剪后再传给脚本，否则会报尺寸错误。程序只在 ROI 中进行检测，浏览器也只显示带框的 ROI。

权重仍由完整图训练，未重训；现在推理先裁剪，再使用 `imgsz=384` 等比例缩放和补边。实际测试显示对当前权重，裁剪后用 384 比直接放大到 1280 更合适。检测时不随机移动或旋转画面。

模型只有一个目标类别：`0: plate_screw`。每颗板件螺丝单独输出检测框，`count = len(detections)`，数量不固定。空孔、夹具上的其他螺钉和拆装工具不作为目标。

## 浏览器实时检测

保持已有 `dds_camera.py` 5001 相机服务运行，再在另一个终端执行：

```bash
cd /home/flyfuture/g2_hinge_assembly && \
.venv-sam3/bin/python -m g2_adapter.live_right_plate_screws_web \
  --model models/right_plate_screw_yolo_20261007/best.pt \
  --camera-url 'http://127.0.0.1:5001/get_all_images?indices=18' \
  --confidence 0.5 \
  --interval 0.25 \
  --host 127.0.0.1 \
  --port 8793
```

在本机浏览器打开 **http://127.0.0.1:8793**。显示 255×380 裁剪区域、每颗螺丝的框、螺丝数量和置信度。网页按比例放大显示，不改变裁剪坐标。检测间隔目标为 0.25 秒，实际更新速度取决于相机和推理耗时。

`Ctrl+C` 结束预览。此脚本读取已有相机服务，不自动启动 DDS 服务，不发送机器人动作，不持续保存图像。

接口：`GET /status` 返回最新检测 JSON，`GET /frame` 同时返回 JSON 和带框裁剪图的 JPEG data URL。相机不可用时 `ok=false`、`count=null`，网页不将断流当成 0 颗；成功时 `ok=true`。读取接口的程序可按 `updated_at` 检查结果是否过期。

## 从已运行的相机服务读取一张图

先确保你已运行 `dds_camera.py` 的 5001 服务。下面的命令只读取右手彩色相机 `/camera/hand_right_color` 的一帧，识别后退出，不会启动相机服务。

```bash
cd /home/flyfuture/g2_hinge_assembly && \
.venv-sam3/bin/python -m g2_adapter.predict_right_plate_screws \
  --model models/right_plate_screw_yolo_20261007/best.pt \
  --camera-url 'http://127.0.0.1:5001/get_all_images?indices=18' \
  --confidence 0.5 \
  --output "outputs/right_plate_screws/run_$(date +%Y%m%d_%H%M%S_%N)"
```

每次运行检测一张图。程序要求右手彩色图可用且图像年龄不超过 500 ms。

## 识别本地图片

将 `--image` 替换为你的 1280×1056 右手相机图片路径。下面使用已有空孔测试图，可以直接运行，不需要相机服务。

```bash
cd /home/flyfuture/g2_hinge_assembly && \

  --model models/right_plate_screw_yolo_20261007/best.pt \

  --output "outputs/right_plate_screws/image_$(date +%Y%m%d_%H%M%S_%N)"
```

`--image` 与 `--camera-url` 二选一。`--output` 必须是尚不存在的目录，以免覆盖已有结果。

## 输出和如何读取结果

指定的输出目录会生成：

- `source.jpg`：输入原图。
- `crop.jpg`：255×380 裁剪原图。
- `detections.jpg`：255×380 裁剪图上的检测框。
- `detections.json`：螺丝数量、每个框的置信度和坐标。

终端也会输出同样的 JSON。空孔图示例：

```json
{
  "count": 0,
  "detections": [],
  "crop_xyxy": [525, 435, 780, 815],
  "crop_width": 255,
  "crop_height": 380,
  "imgsz": 384,
  "bbox_coordinate_system": "bbox_xyxy: full image; bbox_crop_xyxy: ROI image",
  "model": "models/right_plate_screw_yolo_20261007/best.pt"
}
```

有螺丝时，`detections` 的每一项包含 `class_id`、`confidence`、`bbox_xyxy` 和 `bbox_crop_xyxy`。`bbox_xyxy` 仍为完整原图上的 `[左, 上, 右, 下]` 像素值；`bbox_crop_xyxy` 为裁剪图坐标。两者左上角原点相差 `(525,435)`；这里没有输出机器人坐标。

## 在 Python 中直接调用权重

使用项目的 `.venv-sam3/bin/python` 运行下面的代码；将图片路径替换为实际输入。

```python
from ultralytics import YOLO
import cv2
from g2_adapter.right_plate_screw_detection import detect

model = YOLO('/home/flyfuture/g2_hinge_assembly/models/right_plate_screw_yolo_20261007/best.pt')
image = cv2.imread('/home/flyfuture/g2_hinge_assembly/datasets/right_plate_screw_raw/20261007_livecheck01/frame_0000.jpg')
crop, preview, data = detect(model, image, confidence=0.5)
print(data)  # data['count'] 是数量，data['detections'] 是每颗螺丝的框和置信度
cv2.imwrite('screw_detections.jpg', preview)
```

从项目根目录运行上述代码，使 Python 可以导入 `g2_adapter`。共用 `detect()` 确保裁剪范围和推理尺寸与命令行及实时预览一致。

## 参数及常见问题

- 默认置信度阈值为 `0.5`；提高会更严格，降低可能增加误检。已报告的测试结果采用 `0.5`。
- `No fresh right-hand color frame`：检查相机服务中右手彩色图是否可用，以及图像是否更新。
- 连接失败：检查已有相机服务地址和端口。脚本不自动启动服务。
- `Expected a full 1280x1056 right-hand image before ROI cropping`：输入尺寸不匹配；使用原始右手相机图。
- 输出目录已存在：更换 `--output` 路径。

当前留出原图 22 张计数全部正确，后续 12 张空孔图无误检；2 颗和 4 颗真实样本各只有 3 张。验证来自同一工位，更换工位或视角后需要重新核对效果。
