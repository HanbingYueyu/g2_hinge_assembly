# 铰链板螺丝检测模型（2026-10-07）

单类别 `plate_screw` 目标检测：每颗螺丝输出独立框和置信度，数量等于通过置信度阈值的框数。没有按数量分类，也没有限制最多四颗。只识别板件目标螺丝，空孔不标注。

输入为右手相机完整 1280×1056 图，程序先按 `[525,435,780,815]` 裁剪为 255×380；当前推理 imgsz=384、conf=0.5、IoU=0.5。裁剪范围对应第一张局部参考图，推理没有随机裁剪或旋转。权重仍是完整图训练的原权重。

YOLO11n，从已有检测权重初始化，训练新单类别头；没有覆盖原模型。训练 40 epochs，早停，最佳 epoch 15。验证 mAP50=0.995，mAP50-95≈0.986。

原完整图推理的逐框检查（匹配 IoU≥0.5，置信度≥0.5）：
- 留出原图 22 张，覆盖 0–4 颗；46 个螺丝框，漏检 0、多检 0，计数 22/22 正确。
- 留出图额外 ±12° 旋转、±45/35 px 平移共 44 张；92 个框，漏检 0、多检 0，计数 44/44 正确。这是合成扰动测试，不是独立真实样本。
- 后续另采 12 张真实空孔图，没有用于训练；全部输出 0，无空孔误检。

数据来自同一工位和采集段，2 颗和 4 颗各仅 3 张真实原图。上述结果不能代表新工位、任意遮挡或更大视角变化。
