# SpaceMouse Compact G2 遥操作实施计划

目标：按已确认交互控制左右末端 6D 位姿；左按钮切手，右按钮切换当前夹爪，无使能键。

设计：新增 Linux Compact HID 输入、独立单线程遥操作状态机和命令行入口，复用 G2Controller 的运动门控与末端发送接口。预览不初始化 GDK；运动仅在 --allow-motion 下运行。既有视觉控制流不改动。用户已批准实施，当前 GPT-6 在原工作区执行，保留已有未提交修改，不调用其他模型、不执行真机。

- [x] 输入与状态机测试先行：原始报告解码、按键边沿、六轴限速、四元数、回中取消目标、切手等待命令有效期、过期输入和越界退出。
- [x] 新增 `g2_adapter/spacemouse_input.py`：识别 256f:c635，只读非阻塞 hidraw；平移和旋转独立时间戳；不将轮询空读当新输入；缓存耗尽限制和断连报错。
- [x] 新增 `g2_adapter/spacemouse_teleop.py`：50 Hz 唯一发送者，速度积分、基座坐标系旋转及跟随误差限制；不设置累计工作空间位移/旋转上限；回中和退出使用实测位置消除待追赶目标；切换等待旧命令到期再采集新手位姿；夹爪目标随位姿同步发出。
- [x] 新增 `g2_adapter/run_spacemouse_gdk.py`：默认输入/模拟目标预览、设备列表、速度和轴映射参数、Ctrl+C 清理；GDK 延迟导入，启动不切换模式。
- [x] 补充 `常用命令.md` 与使用文档：预览/真机命令、回中初始化、两按钮语义、坐标映射、设备权限、限幅和未验证的真机边界。
- [x] 运行新测试、现有 control/safety 回归、CLI 预览/参数测试、语法检查与 diff 检查；记录结果。

验证命令：`python3 -m unittest discover -s g2_adapter -p 'test_spacemouse*.py' -v`；`python3 -m unittest discover -s g2_adapter -p 'test_control.py'`；`python3 -m unittest discover -s g2_adapter -p 'test_safety.py'`。

不变量：不发送运动默认关闭；真机启动先检查状态并切换/确认 GDK `control_mode=1`，失败不发送运动；不并发运行两侧位姿流；左按钮松开只允许平移、按住开放完整 6D，双击才切手，长按不形成双击；右按钮长按不重复夹爪动作；运动输入过期不能被按钮包续命；启动和切换须检测中立输入；目标不累积到远离实测；不自动重连恢复运动。

结果：SpaceMouse 测试通过（包括仓库 Python 3.10 启动环境）；25 项 control、5 项 safety 回归通过；新模块语法检查及 git diff --check 通过。GPT-6 只读审查发现的同批 HID 切手时序、夹爪重新同步问题已加失败复现测试后修复，复核通过。后续将目标积分基准改为每周期最新实测位姿，避免执行延迟累积为跟随误差。原有文件仅在常用命令.md 追加本功能说明，未改动既有控制实现。

设备检查：sysfs 识别到 `/dev/hidraw3`；沙箱未暴露设备节点，授权的沙箱外 2 秒只读预览也因当前用户无读取权限而未能打开设备。需按 SPACEMOUSE.md 配置设备访问权限后现场验证六轴输入。未初始化 GDK、未执行真机动作。
